# 字块冲刺 · Word Block Rush

一个纯前端的英文打字消除小游戏：单词方块从顶端落下，玩家逐字母输入拼出单词把它消掉，在方块落地前守住爱心。

无需安装、无需联网，双击 `index.html` 即可开玩。

## 玩法

- 方块上带着英文单词，从顶部缓慢下落
- 直接敲键盘输入：只有当前输入是某个方块单词的前缀时才会高亮对应方块
- 完整拼出单词即消除并得分，连击越高单次得分越高
- 打错字母只清空输入并中断连击，不扣爱心
- 方块落到判定线会碎一颗爱心，3 颗碎完本局结束

## 模式

| 模式 | 说明 |
| --- | --- |
| 单机闯关 | 每关有目标分与倒计时，达标解锁下一关，进度自动保存 |
| 限时冲刺 | 60 秒内冲击个人最高分 |
| AI 对战 | 左右双跑道，本地 AI 按反应时间与打字速度读词、输入、偶尔失误，先碎完爱心或比分落后者判负 |
| 错词复习 | 用错词本里的单词开一局专项练习 |

## 词库

7 套离线内嵌词库，共 1,848 个单词：四级、六级、考研、高中、小学、编程关键字、AI 术语。词库按长度分三档难度，关卡目标分与关卡数量按词库规模自动计算。

## 操作

| 按键 | 作用 |
| --- | --- |
| 字母 / 数字 | 输入，自动匹配前缀 |
| Backspace | 清空当前输入 |
| Esc | 暂停 / 继续 |

> 需要英文输入法，中文输入法状态下会提示切换。

## 运行

直接打开 `index.html`，或在本地起一个静态服务器：

```bash
python -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 技术

- 原生 HTML / CSS / JavaScript，无框架、无构建、无外部依赖
- 脚本按 `words → storage → ui → game → main` 顺序加载
- 成绩、关卡进度、错词本存放在 `localStorage`，换设备或清缓存后不保留
- 无后端，全部逻辑在浏览器本地运行

## 已知局限

- 仅支持英文与数字输入
- 未适配移动端触屏键盘，小屏只保证页面可滚动
- AI 对战为本地规则模拟，不是联网对手
