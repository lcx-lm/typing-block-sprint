# 字块冲刺 · 英文打字闯关小游戏

《人工智能导论》期末大作业（路线 B：小游戏）。

代码仓库：https://github.com/lcx-lm/typing-block-sprint

纯前端单机闯关游戏：方块携带英文单词下落，玩家逐字母敲出完整单词即可消除得分。每关限时冲击目标分，达标后进入下一关；每关 3 颗爱心，爱心碎完或时间用完则本局结束。

## 运行方式

直接双击 `index.html`，用 Chrome 或 Edge 打开即可。

- 无需安装、无需构建、无需联网
- 不使用 CDN、不使用 npm、不使用 ES Module、不使用 fetch，因此 `file://` 协议下也能正常运行
- 建议分辨率 1366×768 及以上

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 字母 / 数字键 | 逐字母输入当前单词 |
| Backspace | 清空当前输入（不扣爱心） |
| Esc | 暂停 / 继续 |
| 鼠标点击 | 确保页面获得键盘焦点 |

> 请使用英文输入法。检测到输入法组合输入时会给出提示，并暂停输入判定，避免吞键误判。

## 规则

### 关卡

- 关卡数不写死，由词库词数自动计算：每关约 8 个词，最少 6 关、最多 50 关
- 每关限时 50 秒，达到本关目标分即过关，目标分随关卡递增
- 过关后爱心重置为 3 颗，词池切换到下一关的单词
- 关卡全部通过即通关；时间用完或 3 颗爱心碎完，本局结束

### 生命与计分

- 每关开始时重置 3 颗爱心
- 方块掉到底部，碎掉 1 颗爱心，该方块被移除，连击归零
- 打错字母只清空连击，不扣爱心
- 3 颗爱心全部碎掉，本局结算

计分公式：

```
单次消除得分 = 单词长度 × 10 × 难度系数 × (1 + 连击数 × 0.1)
```

难度系数：简单 0.8 / 普通 1.0 / 困难 1.3。

## 功能清单（P0）

- 首页 HOME：昵称修改（12 字符上限，本地保存）、段位占位卡、最高分/最佳 WPM、模式选择、排行榜 Top5、错词本（按词库记录打错的单词，最多 120 个）、设置、帮助
- 选择流程 SELECT：7 套词库（卡片显示词量与关卡数）、3 档难度、开始/返回
- 对局 PLAYING：关卡制（关卡进度、本关目标分、50 秒倒计时）、方块下落、前缀高亮、完整输入消除、连击、3 颗爱心生命、暂停、失焦自动暂停
- 结算 RESULT：到达关卡与结束原因、得分、准确率、WPM、最高连击、破纪录标记、本局打错单词（去重最多 10 个）、再来一局/换词库/返回首页
- 持久化：昵称、最高分、最佳 WPM、排行榜 Top10、音效设置、帮助已读标记、关卡解锁进度、错词本
- 设置：音效开关、清空排行榜（二次确认）、重置所有数据（二次确认）
- 帮助：规则、键位、关卡/生命与连击说明，首次进入自动弹出
- 音效：Web Audio API 实时合成，无外部音频文件

未实现模式（限时冲刺、AI 对战）仅保留禁用按钮与"后续版本"占位，不包含任何逻辑。

## 目录结构

```
字块冲刺/
  index.html            页面结构（四个屏幕 + 弹窗容器）
  css/style.css         样式（默认亮色，可切换暗色主题）
  js/words.js           词库（ECDICT 衍生的 5 套考试词库 + 自建代码/AI 术语，内联为全局常量）
  js/storage.js         localStorage 封装（带内存降级）
  js/ui.js              页面切换、HUD、弹窗、排行榜表格
  js/game.js            游戏核心：生成、下落、输入判定、生命、计分、暂停、结算
  js/main.js            入口：数据读写、页面路由、事件绑定、结算落库
  README.md             本文件
  docs/
    项目说明.md          选题理由、目标用户、功能结构、使用方法与局限
    AI使用声明.md        AI 使用声明（已按实际使用情况填写）
    自测清单.md          功能与边界用例的自测记录
```

脚本按 `words → storage → ui → game → main` 顺序以普通 `<script>` 标签加载，无模块依赖。

- `typingBlock_nickname`
- `typingBlock_bestScore`
- `typingBlock_bestWpm`
- `typingBlock_leaderboard`
- `typingBlock_settings`
- `typingBlock_helpSeen`
- `typingBlock_guideSeen`
- `typingBlock_levelProgress`
- `typingBlock_wrongBook`

浏览器禁用本地存储时自动降级为内存存储，并提示一次"刷新后会丢失"。

## 已知问题与限制

1. 仅支持英文与数字输入，不支持中文输入法模式（本阶段明确不做）。
2. 未做移动端触屏键盘适配；小屏仅保证页面可滚动、游戏区不被遮挡。
3. 段位、排位分、限时冲刺、AI 对战均为占位，未接入逻辑。
4. 词库已扩充到约 2200 词，超长对局仍可能出现重复单词；词库离线内嵌，不随远程自动更新。
5. 无后端，排行榜为本地数据，换设备或清缓存后不可恢复。

## 词库来源说明

`js/words.js` 中的四级、六级、考研、小学、高中 5 套词库由开源项目 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT License）加工生成：按考试标签筛选、按词频排序、精简中文释义，并过滤掉过短的虚词。代码关键字与 AI 术语为自建示例词库。

生成的词库为纯静态数据，随页面一起加载，运行时不需要联网或调用任何 API。ECDICT 的 MIT 许可允许使用、修改与再分发，本项目在此保留其来源与授权说明。
