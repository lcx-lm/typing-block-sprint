# 字块冲刺 · 英文打字闯关小游戏

《人工智能导论》期末大作业（路线 B：小游戏）。

代码仓库：https://github.com/lcx-lm/typing-block-sprint

纯前端单机闯关游戏：方块携带英文单词下落，玩家逐字母敲出完整单词即可消除得分。提供单机闯关、限时冲刺、AI 对战三种模式；单机闯关每关限时冲击目标分，达标后进入下一关，每关 3 颗爱心。每局结束按胜负结算排位积分，积分对应青铜到钻石五个段位。

## 运行方式

直接双击 `index.html`，用 Chrome 或 Edge 打开即可。

- 无需安装、无需构建、无需联网
- 不使用 CDN、不使用 npm、不使用 ES Module、不使用 fetch，因此 `file://` 协议下也能正常运行
- 建议分辨率 1366×768 及以上

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 字母 / 数字键 | 逐字母输入当前单词 |
| Backspace | 清空当前输入（不扣爱心） |
| Esc | 暂停 / 继续 |
| 暂停中的「退出本局」 | 整局一个单词都没消除时直接退出、不扣积分并回到首页；已有消除记录时会先弹确认框（标题与正文居中，关键数字用红色标出），显示本关已得分数、还差多少词过关与本局积分变化（AI 对战中退出视为认输）。确认后若本次退出会扣分，则进入失败结算页：大字「失败」、数据区为本局四项指标与错词，积分行显示负数，金色进度条从结算前位置倒退到扣分后的位置；不扣分（如冲刺 400 分以上退出）或通关弹窗点「退出」时仍直接回首页。刚进入下一关、本关还没消除单词时退出，不扣积分也不计胜负；一旦在本关消除过单词，就视为本关未通过，直接扣 10 积分（不会因为前面通过了几关而改成加分） |
| 鼠标点击 | 确保页面获得键盘焦点 |

> 请使用英文输入法。检测到输入法组合输入时会给出提示，并暂停输入判定，避免吞键误判。

## 规则

### 关卡

- 关卡数不写死，由词库词数自动计算：每关约 8 个词，最少 6 关、最多 50 关
- 每关限时 50 秒，达到本关目标分即过关，目标分随关卡递增
- 过关后爱心重置为 3 颗，词池切换到下一关的单词
- 关卡全部通过即通关；时间用完或 3 颗爱心碎完，本局结束

### 生命与计分

- 每关开始时重置 3 颗爱心
- 方块掉到底部，碎掉 1 颗爱心，该方块被移除，连击归零
- 打错字母只清空连击，不扣爱心
- 3 颗爱心全部碎掉，本局结算

计分公式：

```
单次消除得分 = 单词长度 × 10 × 难度系数 × (1 + 连击数 × 0.1)
```

难度系数：简单 0.8 / 普通 1.0 / 困难 1.3。

### 出块

单词采用「洗牌袋」抽取：把当前词池按难度长度过滤后整体洗牌，再按顺序逐个取出，抽完一整轮才重新洗牌（重新洗牌时新一轮第一个词会避开上一轮的最后一个词）。这样抽完一整轮之前不会重复遇到同一个词，同时顺序仍是随机的；AI 对战里玩家与 AI 共用同一个袋子，两条跑道也不会刷出同一个词。错词复习的词池很小，仍沿用同屏去重、随机抽词与放慢出块的原有逻辑。

### 模式

- **单机闯关**：选词库、难度与关卡，逐关解锁；每关 50 秒，达到目标分过关。
- **限时冲刺**：整库词池单局 60 秒，不设关卡目标，3 颗爱心耗尽或时间用完结束，冲击最高分。
- **AI 对战**：左右双跑道，各 60 秒。AI 会读词、逐字输入并偶尔打错，打错时方块变红并显示「✕ 打错了」；也会小概率走神，整词漏看（方块显示「✕ 漏看了」），漏看的词落地会扣 AI 爱心；双方各有 3 颗爱心。任一方爱心碎完即判负；一方分数占比达到 70% 并保持 3 秒可压制获胜；否则时间到按比分判定。
- **错词复习**：在首页错词本点「复习错词」，用当前词库收集到的错词打一局 60 秒。不计入成绩记录与段位积分，只用来巩固错词。错词越少出块越慢（少于 6 个时按数量放大出块间隔），且同屏不会出现重复单词。

AI 对手是一个本地智能体（感知 → 决策 → 行动 → 反馈），用有限状态机加可控随机扰动模拟人的反应与失误，不联网、不调用大模型。完整的 Agent 模型、状态机与参数说明见 `docs/项目说明.md` 第 5.9 节。

### 段位与积分

- 段位门槛：青铜 0–99 / 白银 100–299 / 黄金 300–599 / 铂金 600–999 / 钻石 1000 以上（段位弹窗内按档位列出了每个段位对应的分数段与当前所在段位）。
- 单机闯关：本关通过才算胜利（全部通关 +30；在通关弹窗退出按本局通过关数 +20 或 +5；每首次通过一关额外 +10）；爱心耗尽、时间到或中途退出时本关未通过，一律 −10，不会因为前面已通过的关卡而加分。
- 限时冲刺：600 分及以上 +15；400–599 分 +5；低于 400 分 −8。
- AI 对战：获胜 +20；平局 +5；失败 −10（胜负以爱心、拔河条压制或时间到比分判定为准）。
- 积分最低为 0。首页段位徽章右上角的「!」可查看当前段位、积分进度、战绩与完整规则。

## 功能清单（P0）

- 首页 HOME：昵称修改（12 字符上限，本地保存）、段位徽章与段位说明弹窗、最高分/最佳打字速度、三种模式入口、最近表现（最近 10 局走势图，横轴时间、纵轴分数、金色平均线，悬停或 Tab 聚焦节点显示该局得分；右上角「查看详细」可打开最近 20 局的全部记录）、错词本（按词库记录打错的单词，最多 120 个，可一键复习）、设置、帮助
- 选择流程 SELECT：7 套词库（卡片显示词量与关卡数）、3 档难度；单机模式显示关卡网格，冲刺/AI/错词复习模式隐藏关卡并切换按钮文案
- 对局 PLAYING：单机为关卡制（关卡进度、本关目标分、50 秒倒计时；HUD 左上角只显示本关分数，进入下一关即清零，不累计前几关）；达标后弹出与结算页同格式的祝贺界面——居中「第 N 关」小标题、绿色「通关」大字逐字从上方掉落、本关得分/本关准确率/本关打字速度/本关最高连击四张卡片，卡片下方是与结算页同一套的本局打错单词（去重最多 10 个，没有错词时显示「本局没有打错的单词，漂亮」），再往下是与结算页同一套的本局加分进度条（本局总计积分 +N、金色进度条涨到结算后位置、当前总积分与段位、X/100 与距下一段位文案），伴随礼炮彩带与通关音效，可选择进入下一关或退出；冲刺与 AI 对战为 60 秒单局，HUD 隐藏关卡/目标；AI 对战为左右双跑道，顶部 HUD 左右分栏（左半为我方分数/生命/连击/当前输入，右半为 AI 分数/生命/连击/输入，剩余时间居中），暂停按钮位于顶栏且仅对局中显示，顶部拔河条显示双方分数占比，AI 会读词、逐字输入、打错停顿、走神漏词与掉块扣心；方块下落、前缀高亮、完整输入消除、得分飘字、连击弹跳、3 颗爱心生命、暂停、失焦自动暂停
- 结算 RESULT：单页呈现——大字显示本局结论（所有结论都逐字从上方掉落：失败/挑战完成/全部通关/胜利等均先停顿约 0.6 秒，再让每个字依次落下；大字上方预留一段专用掉落区，字只在预留区内下落，不会压到上方标题或下方数据卡片的边框；单机因爱心碎完失败时先只显示居中的「第 N 关」，然后「失」「败」两个字先后掉落到位），数据区按模式展示：单机与限时冲刺统一为得分/准确率/打字速度/最高连击四张卡片；冲刺大字固定为绿色「挑战完成」，卡片下方另起一行「历史最佳 X 分 · 最佳打字速度 Y 词/分」做对比，只有真正刷新最高分才额外显示金色「新纪录」徽章，没刷新则完全不作提示；AI 对战为大字胜利/失败/平局 + 放大的「你 : AI」比分与一句「你领先 AI N 分 / AI 领先你 N 分 / 双方打成平局」，下方按结束原因给出辅助文案（成功压制 AI / 被 AI 反超 / AI 爱心耗尽 / 你的爱心耗尽 / 时间到，比分领先 / 时间到，比分落后 / 双方势均力敌），再接你与 AI 的左右对比表（得分/最高连击/剩余爱心）；三种模式下方统一为「本局需要加强的单词」错词块（去重最多 10 个，附提示「这些单词在本局中出现过输入错误，可以在错词本中继续练习。」，无错词时显示「本局没有打错的单词，继续保持！」）；失败局不显示新纪录徽章。数据区下方直接内嵌本局积分：等大字掉完落地后，左侧「本局总计积分 ±N」先弹出（加分金色、扣分红色），金色发光进度条再从结算前的进度前进或后退到结算后位置，右侧同步补间显示当前总积分与段位名，最后揭示 X/100 与「距白银还差 N 分」，无需再翻页；底部为再来一局/换词库/返回首页；错词复习不计段位积分，只显示提示与三按钮
- 持久化：昵称、最高分、最佳打字速度、最近 20 局成绩、音效与主题设置、帮助已读标记、关卡解锁进度、错词本、段位积分与战绩
- 设置：音效开关、主题切换、重新观看新手引导、重置所有数据（二次确认）

## 目录结构

```
字块冲刺/
  index.html            页面结构（四个屏幕 + 弹窗容器）

  js/ui.js              页面切换、HUD、弹窗、成绩记录表格
  js/game.js            游戏核心：生成、下落、输入判定、生命、计分、暂停、结算
  js/main.js            入口：数据读写、页面路由、事件绑定、结算落库
  README.md             本文件
  docs/
    项目说明.md          选题理由、目标用户、功能结构、使用方法与局限
    AI使用声明.md        AI 使用声明（已按实际使用情况填写）

```

脚本按 `words → storage → ui → game → main` 顺序以普通 `<script>` 标签加载，无模块依赖。

## 已知问题与限制

1. 仅支持英文与数字输入，不支持中文输入法模式（本阶段明确不做）。
2. 未做移动端触屏键盘适配；小屏仅保证页面可滚动、游戏区不被遮挡。
3. AI 对战为本地规则模拟对手，会按反应时间、打字速度与失误率行动，但不涉及真实模型或联网对战。
4. 词库为离线内嵌的静态数据，共 7 套、1848 词（四级/六级/考研/高中各 400、小学 200、代码关键字与 AI 术语各 24），不随远程自动更新；出块用洗牌袋，抽完一整轮才重新洗牌，只有超过整库容量的超长对局才会再次遇到同一个词。
5. 无后端，成绩记录、段位与积分均为本地数据，换设备或清缓存后不可恢复。

## 词库来源说明

`js/words.js` 中的四级、六级、考研、小学、高中 5 套词库由开源项目 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT License）加工生成：按考试标签筛选、按词频排序、精简中文释义，并过滤掉过短的虚词。代码关键字与 AI 术语为自建示例词库。

生成的词库为纯静态数据，随页面一起加载，运行时不需要联网或调用任何 API。ECDICT 的 MIT 许可允许使用、修改与再分发，本项目在此保留其来源与授权说明。
