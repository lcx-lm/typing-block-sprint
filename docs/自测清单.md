# 自测清单

> 测试方式：直接双击 `index.html`（`file://`）与本地静态服务器两种方式各跑一遍；浏览器为 Chrome / Edge。
> 结果列说明：「通过」为开发过程中实际验证过的项目；「待复测」请在提交前按步骤执行一遍，通过后再改为「通过」，未执行的不要勾选。

## H. 已知限制（不列为缺陷）

- 不支持中文输入法组词上屏，仅支持英文与数字。
- 未做移动端触屏键盘适配。
- 段位、限时冲刺、AI 对战为占位，无实际逻辑。
- 排行榜与进度只存在本地，换设备或清缓存后不可恢复。
